# 運用ガイド

開発環境の準備や変更の検証は [開発ガイド](development.md) を参照する。ここでは公開・保守の目的に応じた手順を案内する。

## 動画を公開・更新する

1. [動画とサムネイルの公開手順](r2_publish_runbook.md) に沿って公開対象を選び、素材と動画一覧を用意する。`public/videos.json` は Git 管理しない。
2. [公開前チェックリスト](pre_publish_checklist.md) でデータ、素材、画面を確認する。件数は固定値ではなく、今回公開する対象と照合する。
3. [Cloudflare Pages デプロイ手順](cloudflare_pages_deploy.md) に沿って本番反映し、公開後の表示と配信を確認する。

共有先の表示については [共有プレビュー](share_previews.md)、いいねについては [likes API の確認手順](likes_api_smoke_test.md) と [連打・不正利用への対策](likes_rate_limiting_policy.md) を参照する。

## セキュリティを保守する

毎朝7時（日本時間）のローカル監視で Node.js と依存関係を確認する。実行には Mac とアプリの起動、必要なネットワークと認証が必要で、常時監視ではない。

- [更新の準備と自動反映](security-update-preparation.md)：軽微なパッチ更新の自動反映条件、それ以外の更新案の準備、通知先を定める。軽微な更新の正常完了はチャットのみで知らせる。
- [重大な脆弱性への緊急停止](emergency-shutdown.md)：停止の判断基準、停止方法、残る公開範囲を定める。停止後の再公開はユーザーの判断を待つ。
- [セキュリティ保守記録](security-maintenance.md)：過去の停止・更新・再公開と、その時点の確認結果を記録する。

自動反映や緊急停止の権限・条件は、上記の各方針を正とする。このガイドに手順を重複させず、条件を変更するときは該当する方針と定期監視の設定を同期する。
