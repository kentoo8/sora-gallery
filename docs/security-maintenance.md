- 本番の動画一覧はローカルの公開用データと一致した。個別動画ページの共有用メタ情報と、いいね API の JSON 応答も確認した。

その後、重大な脆弱性を検知した場合の自律的な緊急停止についても許可を得た。判断基準・停止範囲・復旧条件は [緊急停止方針](emergency-shutdown.md) に記載する。通常のデプロイや自動再公開の権限には広げない。

## 再公開前

ローカル `dist/` は通常のギャラリーのビルド成果物であり、停止案内ではない。一時停止中に通常のデプロイコマンドを実行すると再公開されるため、反映の可否を判断してから実行する。

```bash
mise install
mise exec -- node --version
mise exec -- npm ci
mise exec -- npm audit
mise exec -- npm test
mise exec -- npm run lint
mise exec -- npm run build
```

ブラウザで一覧、検索、個別動画、再生・音声、いいねを確認する。Node.js 本体と開発用ツールの残る問題も確認してから、再公開の可否を判断する。

再公開の本番反映はユーザーのターミナルから行う。手順は [Cloudflare Pages デプロイ手順](cloudflare_pages_deploy.md) を参照。

プレビュー制限を解除する場合は、Pages のプレビュー用 Access 設定を確認してから解除する。本番の再デプロイでこの制限も解除されると想定しない。
