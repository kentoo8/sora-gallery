## 再公開前

現在のローカル `dist/` は通常のギャラリーのビルド成果物であり、停止案内ではない。通常のデプロイコマンドを実行すると再公開されるため、修正と動作確認が完了するまでデプロイしない。

```bash
npm ci
npm audit
npm test
npm run lint
npm run build
```

ブラウザで一覧、検索、個別動画、再生・音声、いいねを確認する。Node.js 本体と開発用ツールの残る問題も確認してから、再公開の可否を判断する。

再公開の本番反映はユーザーのターミナルから行う。手順は [Cloudflare Pages デプロイ手順](cloudflare_pages_deploy.md) を参照。

プレビュー制限を解除する場合は、Pages のプレビュー用 Access 設定を確認してから解除する。本番の再デプロイでこの制限も解除されると想定しない。
