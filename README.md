# sora-gallery

選別済みの Sora 生成動画を Web 公開するためのギャラリーです。動画の検索、タグ絞り込み、連続再生、URLの共有、いいねに対応しています。

## 動画を見る・共有する

再生画面の動画部分をクリック／タップすると、一時停止・再生を切り替えられます。スマホでは縦スワイプで前後の動画へ移動できます。

動画は音ありで再生を試みます。音なしで始まった場合は「音を出す」を押してください。音の設定はページを開いている間、次の動画にも引き継がれます。再生ボタンが表示された場合は、押すと再生を試みます。

検索やタグ絞り込み後のURLを共有すると、同じ条件の一覧を開けます。個別動画のURLも共有でき、対応サービスではサムネイルと説明文が表示されます。

## 開発を始める

Node.js と公開用の動画データが必要です。[開発ガイド](docs/development.md) に従って準備してください。mise で指定版の Node.js を使う場合、依存関係の導入と起動は次のとおりです。

```bash
mise install
mise exec -- npm ci
mise exec -- npm run dev
```

動画の管理・選別には、ローカル用の別アプリ [sora-player](https://github.com/kentoo8/sora-player) を利用できます。

## 公開・保守する

[運用ガイド](docs/operations.md) から、動画の公開、本番反映、脆弱性監視、緊急停止の手順を確認できます。
